02 / Address trust

DoorStep Trust Network

Roughly 68 percent of India's population lives where formal street addresses don't exist. Google's Plus Codes solve the coordinate problem, but a code on its own carries no signal of trust, and unclear addressing is a documented factor in delayed emergency response.

Households register a Plus Code, neighbours who know them vouch for it, and a delivery rider or ambulance dispatcher can check the trust tier before ever travelling there. A printable QR marker and a simulated SMS path keep it usable offline.

  • React
  • SQLAlchemy

03 / Payment fraud

Riskky UPI Risk Companion

Government fraud indicators flag risky phone numbers but say nothing about what a specific transaction looks like in context, a gap that scams like fake refund requests and QR amount mismatches live in, especially for users less comfortable in fast, English heavy financial jargon.

Riskky blends a 10 rule engine with a logistic regression classifier, then explains the result in the user's own language, read aloud, with a short cooling off period before a flagged payment can proceed.

  • FastAPI
  • React
  • Scikit-Learn
  • 7 languages

04 / Review integrity

Trustly Neighbourhood Trust Score

A star rating alone hides a lot. A one line review counts the same as a detailed one, a burst of near identical five star reviews reads the same as ones earned over a year, and most platforms don't rank the reviews that already made it past moderation.

Trustly runs four independent, fully documented checks, generic text, rating mismatches, clustered posting dates, anonymous names, and returns which rule fired on which review, not just a final number. No machine learning, no external API.

  • FastAPI
  • React
  • Pytest
  • GitHub Actions
Live app Source
